### 20. Auto-Discovery Registry（自动发现注册系统）

**状态**: 未实现（2026-03-10 决策通过）
**优先级**: 高 — 解决上游同步时下游功能丢失的根本问题
**关联 Skill**: `upstream-safe-design`

**问题背景**:
当前项目有 7 类功能需要在上游「中央注册文件」中手动注册才能生效。每次上游同步，这些注册行有 68% 概率丢失，行为修改有 0% 存活率。

**受影响的中央注册文件**:

| 注册文件 | 功能类型 | 下游项数 | 同步风险 |
|---|---|---:|---|
| `src/index.ts` | Hook 实例化 + 生命周期 | ~35 | 最高 — 同步主冲突点 |
| `src/features/builtin-skills/skills.ts` | Builtin Skill 数组 | ~12 | 高 |
| `src/features/builtin-commands/commands.ts` | 命令模板 | 9 | 高 |
| `src/agents/builtin-agents.ts` | Agent 工厂 | 6 | 中 |
| `src/tools/index.ts` | Tool Record | 7 | 中 |
| `src/mcp/index.ts` | MCP 配置 | 4 | 中 |
| `src/config/schema/hooks.ts` | HookNameSchema enum | ~11 | 高（0% 存活） |

**设计方案**:

```
src/downstream/
├── auto-registry.ts          ← 统一扫描引擎（启动时自动运行）
├── hooks/                    ← 放 hook + manifest.ts 即生效
├── skills/                   ← 放 SKILL.md 即生效
├── commands/                 ← 放命令定义即生效
├── agents/                   ← 放 agent 即生效
├── tools/                    ← 放 tool 即生效
├── mcp/                      ← 放 MCP 配置即生效
├── patches/                  ← 放 wrapper/patch 即自动应用
├── schema-extensions.ts      ← 运行时动态扩展 HookNameSchema
├── snapshot.json             ← 同步前自动快照（用于同步后 diff 补回）
└── manual-patches.md         ← 无法自动化的修改记录（sync 后人工补）
```

**核心机制**:
- 每种类型的模块导出标准 manifest（name, lifecycle, factory 等）
- `auto-registry.ts` 启动时扫描所有子目录，自动注册发现的模块
- 上游文件只需一次性添加 1-2 行调用（如 `await registerDownstream(ctx)`）
- 不需要维护总表 — 目录结构本身就是清单
- 上游不知道 `src/downstream/` 的存在，sync 时不会删除

**对上游行为修改的处理（Pattern C 增强）**:
- 能 wrapper 的：放 `patches/` 目录，用包装器替换原始 handler
- 改数据/配置的：用 `schema-extensions.ts` 运行时覆盖
- 必须改源码的（如 bug 修复）：走 PR 上游，或记录到 `manual-patches.md`

**同步保护流程**:
1. 同步前：自动快照当前注册状态到 `snapshot.json`
2. 同步中：执行 git merge
3. 同步后：diff 快照 vs 当前状态，自动补回丢失项
4. 验证：运行测试确认无回归

**上游文件改动量（一次性）**:
- `src/index.ts`: +1 行 `await registerDownstream(ctx, plugin)`
- `skills.ts`: +1 行 `...discoverDownstreamSkills()`
- 其他注册文件类似，各 +1 行
- 总计碰上游文件 ~7 个，每个只加 1 行

**收益**:
- 新增下游功能：只建文件，不碰上游 → 100% 存活
- 上游同步后：自动恢复所有注册 → 从 68% 提升到 ~100%
- 维护成本：从每次 sync 手动补 30+ 行降到 0
