### Root cause: `output.content` vs `output.output` (2026-03-18)
- **Bug**: Both failure-counter and debugging-injector hooks read `output.content` to detect failures/successes, but the OpenCode plugin SDK `tool.execute.after` output type provides the tool result text in `output.output`, not `output.content`. Since `output.content` was always `undefined`, `outputContent` was always `""`, and no patterns ever matched — making both hooks completely inert.
- **SDK type** (`@opencode-ai/plugin` v1.1.26):
  ```ts
  "tool.execute.after"?: (input: { tool: string; sessionID: string; callID: string; args: any }, output: { title: string; output: string; metadata: any }) => Promise<void>
  ```
- **Fix applied**:
  - `src/hooks/failure-counter/index.ts`: changed `output.content` → `output.output`, updated type annotation
  - `src/hooks/debugging-injector/index.ts`: changed `output.content` → `output.output`, updated type annotation
